# ⛷️ Sky Resort Analysis | Power BI Dashboard

## 📌 Project Overview

The **Sky Resort Analysis Dashboard** is an end-to-end Power BI analytics project designed to analyze global ski resorts from multiple business perspectives including:

- 📈 Executive Overview
- 🏔️ Resort Benchmarking
- 👨‍👩‍👧 Customer Segmentation
- ❄️ Snow Intelligence & Seasonality

This project transforms raw resort and snow datasets into an interactive analytical solution focused on operational insights, customer experience, pricing analysis, infrastructure benchmarking, and seasonal snow trends.

---

# 🎯 Business Problem Statement

The ski resort industry operates in a highly competitive and seasonal environment where decision-makers need to understand:

- Which resorts provide the best customer experience?
- Which destinations offer the best infrastructure and terrain?
- How pricing compares across global resorts?
- Which resorts are better suited for families or premium travelers?
- How snow conditions fluctuate throughout the year?
- Which regions demonstrate stronger snow reliability?

However, raw datasets alone do not provide meaningful business insights without proper transformation, modeling, and analytical storytelling.

This dashboard solves that problem by converting fragmented resort and snow data into a centralized decision-making platform.

# 🧹 Data Cleaning & Transformation

### Key preprocessing steps performed:

- Removed null and inconsistent records
- Corrected data types
- Created segmentation columns:
  - Price Band
  - Resort Size
- Developed calculated analytical fields:
  - Family Score
  - Beginner Ratio
  - Advanced Ratio
- Built DAX measures for:
  - Resort KPIs
  - Snow KPIs
  - Infrastructure Metrics
  - Segmentation Analysis
- Designed a structured analytical data model
